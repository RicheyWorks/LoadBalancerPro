# Documentation Archive

This directory preserves superseded planning, campaign, audit, and release-history
records. These files are historical context, not the current build contract,
operator runbook, or evidence source of truth.

- `agent-history/` contains completed or superseded agent/campaign material.
- `project-history/` contains completed plans, audits, reviews, and old release
  evidence.

Current operator guidance remains in `docs/`. Current campaign state remains in
the active board, session manager, and Git/GitHub state.
